# Changelog

All notable changes to TinyIcon are documented in this file.

## v1.1.0 - 2026-09-26

### User-Visible Changes

- Added opening of existing icons, including palettized and PNG-compressed entries
- Added opening or importing files by dropping them on the window
- Added command to add sub-images to an icon
- Added command to delete sub-images from an icon
- Added support for 1, 4, 8 and 16-bit color depths
- Changed saving to keep the color depths of an opened icon
- Changed New Icon dialog to offer every supported color depth and remember the selection per depth
- Fixed indexed icons being displayed incorrectly by non-conformant viewers
- Updated README with a user guide

### Internal Changes

- Added social media preview image to GitHub Pages website
- Added more tests

### Dependency Updates

- Bumped Microsoft.NET.Test.Sdk from 18.8.1 to 18.10.1
- Bumped Microsoft.Xaml.Behaviors.Wpf from 1.1.142 to 1.1.161
- Bumped NUnit3TestAdapter from 6.2.0 to 6.3.0

## v1.0.0 - 2026-07-17

First official release.
